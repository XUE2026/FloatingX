# FloatingX

> Android 悬浮窗宠物/模型展示应用

![version](https://img.shields.io/badge/version-0.0.1--dev-blue)
![Android](https://img.shields.io/badge/Android-8.0%2B-brightgreen)

## 简介

悬浮窗展示 3D/2D 模型宠物。支持 PMX/FBX/Spine 模型导入，内置编辑器。

## 构建

```bash
./gradlew assembleDebug
```
